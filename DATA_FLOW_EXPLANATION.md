## 📊 تدفق البيانات في Telemetry

### عند فتح النافذة:

1. **on_window_opening** (قبل الفتح):
   ```python
   _last_open_time["reports"] = 1234567890.123  # time.perf_counter()
   ```

2. **on_window_opened** (بعد الفتح):
   ```python
   duration = time.perf_counter() - _last_open_time["reports"]
   duration_ms = duration * 1000  # تحويل إلى milliseconds
   
   # تحديث الإحصائيات
   _open_counts["reports"] += 1
   _total_open_time["reports"] += duration_ms
   _open_times["reports"].append(duration_ms)
   ```

3. **حفظ دوري** (كل 10 فتحات):
   ```python
   if _open_counts[window_key] % 10 == 0:
       _save_data()  # حفظ في logs/window_telemetry.json
   ```

### عند إغلاق التطبيق:

```python
# في MainWindow.closeEvent()
telemetry.save_and_reset()  # حفظ نهائي + إعادة تعيين
```
