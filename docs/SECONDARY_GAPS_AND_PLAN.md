# الفجوات الثانوية/الاختيارية وخطة الإغلاق

## 1. دعم الموبايل (Mobile Support)
- **الحالة:** المواصفات مكتوبة بالكامل (`MOBILE_APP_SPECS.md`).
- **الخطوة التالية:**
  - تنفيذ REST API endpoints الضرورية (جميعها متوفرة بالفعل).
  - تطوير تطبيق React Native/Flutter حسب المواصفات.
  - التكامل مع MFA/OTP والتشفير (مدعوم من الخادم).
  - نشر MVP على App Store/Google Play.

## 2. التكاملات الخارجية (External Integrations)
- **الحالة:** لم تُنفذ بعد.
- **الخطوة التالية:**
  - تحديد الأنظمة الخارجية المطلوبة (محاسبة، دفع إلكتروني، SMS، إلخ).
  - بناء واجهات تكامل (API/Webhooks) أو استخدام Zapier/Make.
  - توثيق نقاط التكامل في ملف منفصل.

## 3. لوحات تحكم متقدمة (Advanced Dashboards)
- **الحالة:** لوحة "الرؤى الذكية" مقترحة فقط.
- **الخطوة التالية:**
  - تصميم واجهة رسومية تفاعلية (PySide6/React) تعرض مؤشرات الأداء (KPIs) وتحليلات AI.
  - ربطها بخدمات الذكاء الاصطناعي والتقارير.
  - إضافة تصدير PDF/Excel.

## 4. دعم الموسمية في التنبؤ (AI Seasonality)
- **الحالة:** لم تُنفذ بعد.
- **الخطوة التالية:**
  - تطوير نموذج تنبؤ موسمي (Seasonal Regression/ARIMA) إذا توفرت بيانات كافية.
  - إضافة خيار التبديل بين النماذج في AIService.

## 5. تحليل نصوص المساعد الذكي (NLP)
- **الحالة:** فقط تحليل كلمات مفتاحية بسيط.
- **الخطوة التالية:**
  - دمج مكتبة NLP (spaCy/transformers) لدعم فهم أعمق.
  - تحسين الردود الذكية.
