# إجابة سؤال: هل تستخدم تقنية معينة؟

## الإجابة المختصرة:

**نعم، المشروع يستخدم تقنيات محددة:**

### التقنية الأساسية:
- **Python 3.13** - لغة البرمجة الأساسية
- **PySide6 (Qt6)** - واجهة المستخدم الرسومية (Desktop Application)
- **SQLite** - قاعدة البيانات المحلية

### نوع التطبيق:
- **Desktop Application** (تطبيق سطح مكتب)
- **ليس Web-based** (ليس تطبيق ويب)
- **ليس C# .NET** (لا يستخدم .NET)

---

## الإجابة التفصيلية:

### 1. نوع التطبيق:
**تطبيق سطح مكتب (Desktop Application)** مبني بـ:
- **PySide6** - مكتبة Python لبناء واجهات المستخدم الرسومية
- **Qt6 Framework** - إطار عمل قوي ومتعدد المنصات

### 2. لغة البرمجة:
- **Python 3.13** - لغة البرمجة الأساسية
- **ليس C#** - لا يستخدم .NET Framework

### 3. قاعدة البيانات:
- **SQLite** - قاعدة بيانات محلية خفيفة وسريعة
- **WAL Mode** - وضع الكتابة المتقدم للأداء العالي

### 4. التقنيات الإضافية:
- **FastAPI** (اختياري) - لبناء REST API
- **Argon2id** - تشفير كلمات المرور
- **PyOTP** - المصادقة الثنائية (2FA)
- **Cryptography** - التشفير المتقدم (AES-256-GCM)
- **Pandas & NumPy** - معالجة البيانات والتحليلات
- **scikit-learn** - الذكاء الاصطناعي والتعلم الآلي

---

## المميزات التقنية:

✅ **متعدد المنصات**: يعمل على Windows, Linux, macOS  
✅ **واجهة رسومية حديثة**: باستخدام Qt6  
✅ **أداء عالي**: Connection Pooling و WAL Mode  
✅ **أمان متقدم**: تشفير، 2FA، RBAC  
✅ **ذكاء اصطناعي**: تحليلات تنبؤية و chatbot
