## 📋 التصنيف حسب الوظيفة

### 🗄️ Database Management (إدارة قاعدة البيانات)

#### `database_manager.py` (1,392 سطر)
**الوصف**: مدير قاعدة البيانات الرئيسي  
**المسؤوليات**:
- إدارة الاتصالات (Connection Pool)
- تنفيذ الاستعلامات
- إدارة المعاملات
- Migrations تلقائية
- النسخ الاحتياطي
- تحسين الأداء

**الكلاسات الرئيسية**:
- `DatabaseManager` - المدير الرئيسي

**الدوال الرئيسية**:
- `execute_query()` - تنفيذ استعلام SELECT
- `execute_non_query()` - تنفيذ INSERT/UPDATE/DELETE
- `execute_scalar()` - الحصول على قيمة واحدة
- `get_cursor()` - الحصول على cursor
- `initialize()` - تهيئة قاعدة البيانات
- `_run_migrations()` - تشغيل migrations
