# 🔍 أدوات المراقبة (Monitoring Tools)

## 1. التحقق السريع من WAL Mode

**قبل/أثناء/بعد الاختبار:**

```bash
python scripts/check_wal_mode.py
```

**المخرجات المتوقعة:**
```
✅ ممتاز! WAL mode مفعّل ويعمل بشكل صحيح
   - SQLite في وضع تعدد الخيوط
   - لا يوجد قفل قاعدة البيانات
```

## 2. مراقبة شاملة أثناء الاختبار

**في Terminal منفصل (بينما التطبيق يعمل):**

```bash
# مراقبة لمدة دقيقتين (120 ثانية)
python scripts/monitor_test.py --duration 120

# أو مراقبة لمدة 5 دقائق
python scripts/monitor_test.py --duration 300

# تغيير فترة الفحص (كل 5 ثوانٍ بدلاً من 2)
python scripts/monitor_test.py --duration 120 --interval 5.0
```

**المخرجات:**
- ✅ حالة ملف WAL (موجود/غير موجود)
- 💻 استهلاك CPU (%)
- 💾 استهلاك RAM (MB)
- ⚠️ تحذيرات تلقائية

```bash
# كل 10 ثوانٍ

```

## 🎯 معايير النجاح

### ملف WAL:
- ✅ **يجب أن يكون موجوداً** أثناء تشغيل التطبيق
- ✅ **يختفي تلقائياً** عند إغلاق التطبيق بشكل صحيح

### CPU:
- ✅ **< 10%** في حالة السكون
- ✅ **Spikes لحظية** (< 50%) عند تحميل الصفحات
- ❌ **> 50% مستمر** = مشكلة (حلقة مفرغة)

### RAM:
- ✅ **< 500 MB** للتطبيق الأساسي
- ✅ **< 1 GB** مع 200K+ منتج محمّل

### السجلات:
- ✅ **ترتيب منطقي:** إيقاف → تحميل → إعادة تشغيل
- ✅ **لا أخطاء:** Connection Pool, Timeout, Deadlock

---

**💡 نصيحة:** اترك `monitor_test.py` يعمل في Terminal منفصل أثناء الاختبار للحصول على تقرير شامل.
