# دليل التنظيف والصيانة - Cleanup & Maintenance Guide

## 📋 نظرة عامة

هذا الدليل يوضح كيفية الحفاظ على النظام نظيفاً ومحسناً بعد إكمال التطوير.

## 🧹 سكربتات التنظيف المتوفرة

### 1. فحص الـ Imports غير المستخدمة

```bash
python scripts/check_unused_imports.py
```

**الوظيفة**: يفحص جميع ملفات Python في مجلد `src` ويقترح الـ imports التي يمكن حذفها.

**الاستخدام**: 
- راجع النتائج يدوياً
- احذف الـ imports غير المستخدمة من الملفات المحددة
- احذر من حذف imports قد تكون مستخدمة ديناميكياً

### 2. تنظيف قاعدة البيانات

```bash
python scripts/cleanup_database.py
```

**الوظيفة**: 
- ينفذ `VACUUM` لضغط قاعدة البيانات
- ينفذ `ANALYZE` لتحسين الأداء
- يعرض حجم قاعدة البيانات قبل وبعد التنظيف

**الاستخدام**: 
- يُنصح بتشغيله شهرياً أو عند ملاحظة بطء في الأداء
- **تحذير**: تأكد من عمل نسخة احتياطية قبل التنظيف

### 3. تنظيف ملفات السجلات

```bash
python scripts/cleanup_logs.py
```

**الوظيفة**: 
- يحذف ملفات السجلات الأقدم من 30 يوم
- ينظف تقارير الأعطال القديمة
- يعرض حجم الملفات المحذوفة

**الاستخدام**: 
- يمكن تشغيله أسبوعياً أو شهرياً
- يمكن تعديل `days_to_keep` في السكربت حسب الحاجة

## 🔄 جدولة التنظيف التلقائي

يمكن إضافة هذه السكربتات إلى جدولة Windows Task Scheduler أو cron:

### Windows (Task Scheduler)
1. افتح Task Scheduler
2. أنشئ مهمة جديدة
3. اضبطها لتشغيل `cleanup_database.py` شهرياً
4. اضبطها لتشغيل `cleanup_logs.py` أسبوعياً

### Linux/Mac (cron)
```bash
# تنظيف قاعدة البيانات شهرياً
0 2 1 * * /path/to/python /path/to/cleanup_database.py

# تنظيف السجلات أسبوعياً
0 3 * * 0 /path/to/python /path/to/cleanup_logs.py
```

## ⚠️ تحذيرات مهمة

1. **قاعدة البيانات**: 
   - تأكد من عمل نسخة احتياطية قبل `VACUUM`
   - لا تشغل `VACUUM` أثناء استخدام النظام

2. **السجلات**: 
   - تأكد من عدم حذف سجلات مهمة للتدقيق
   - يمكنك تعديل `days_to_keep` حسب سياسة الشركة

3. **الـ Imports**: 
   - لا تحذف imports قد تكون مستخدمة ديناميكياً
   - اختبر الكود بعد حذف أي imports

## 📝 ملاحظات

- جميع السكربتات آمنة للاستخدام
- يمكن تشغيلها يدوياً في أي وقت
- لا تؤثر على بيانات المستخدمين
